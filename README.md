# B2B-SaaS-Lead-Scoring-System
Sistema inteligente de qualificação de leads para empresas SaaS B2B. O objetivo é automatizar a triagem de novos cadastros, garantindo que o time de vendas foque nos leads com maior probabilidade de conversão.
Módulo de inteligência de um software profissional. 
Sabe esses sistemas caros que grandes empresas de tecnologia vendem? Eles funcionam exatamente assim: uma parte busca os dados e a outra  toma as decisões.

Pois bem, essa daqui toma as deciões! 🚀 
Como fundadora da Conecta TI, eu acabei de criar o diferencial do meu produto. Um sistema que "acha" empresas é comum, mas ter um sistema que analisa e dá nota automaticamente para o potencial de negócio é o que separa os amadores dos profissionais.

A esse projeto é complementado com o Crewai que dá a lista dos clientes em potencial. Queira dar uma olhada!
